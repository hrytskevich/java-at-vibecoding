1. Нужно ли было в принципе писать свой собственный генератор с фамилиями? Было бы проще использовать генератор из datafaker?
проще использовать datafaker, так как он генерирует случайное значение; можно использовать свой генератор, 
если нужны конкретные фамилии, которые должны использоваться, 
но в нашем случае нет такой необходимости, поэтому можно первую часть названия компании тоже генерировать через datafaker
2. Какая из двух библиотек из этого задания может больше пригодиться при написании автотестов - jfiglet или datafaker?
datafaker может быть очень полезен для генерации тестовых данных
3. Каким образом JAR-файлы этих библиотек попали к нам в проект?
эти библиотеки добавили в pom.xml (на сайте https://mvnrepository.com/ для библиотек указаны groupId, artifactId, version, scope для добавления) 
в зависимости (dependencies), выполнили Reload project для того, чтобы они подтянулись, и Maven скачал их к нам в проект
